# Introduction

Python.org is the official website of the Python Software Foundation, dedicated to promoting, protecting, and advancing the Python programming language and community. Our mission is to support the Python community through grants, infrastructure, and various community events.

# Offerings

Python.org offers a wide range of services and resources to the Python community, including:

- **Infrastructure Support**: We maintain python.org, The Python Package Index, Python Documentation, and many other services that the Python community relies on.
- **PyCon US Conference**: We produce and underwrite the PyCon US Conference, the largest annual gathering for the Python community.
- **Membership**: We support the Python Software Foundation through grants, infrastructure, and various community events.
- **Grants Program**: We welcome grant proposals for projects related to the development of Python, Python-related technology, and educational resources.
- **Sponsorship Possibilities**: We have a variety of sponsorship opportunities to support the Python community.
- **Community Survey**: We want to be open about how we can improve transparency, provide opportunities for interaction, and be responsive to suggestions.

# Community

Python.org is committed to being open about how we can improve transparency, provide opportunities for interaction, and be responsive to suggestions. We encourage community members to contribute by filling out the Python Software Foundation Community Survey.
